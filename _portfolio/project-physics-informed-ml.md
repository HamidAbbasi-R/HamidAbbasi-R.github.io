A collection of scientific machine learning and statistical learning projects:

* **[Physics-Informed-ML](https://github.com/HamidAbbasi-R/Physics-Informed-ML):**  
  Interactive tool built in PyTorch to model nonlinear dynamics of the Van der Pol oscillator using a Tensor Basis Neural Network (TBNN), enabling real-time training and physical constraint enforcement.
* **[HMM-synthetic](https://github.com/HamidAbbasi-R/HMM-synthetic):**  
  Interactive dashboard generating synthetic time-series data with specified Markov dynamics, utilizing Hidden Markov Models to evaluate inference and parameter estimation.
* **[Network-Autoregressive-Model](https://github.com/HamidAbbasi-R/Network-Autoregressive-Model):**  
  Discrete-time linear autoregressive modeling for complex networked systems with adjacency constraints and noise parameterizations.
* **[Bayesian Inference & Poll Simulation](https://github.com/HamidAbbasi-R/Bayesian-Inference):**  
  Statistical inference dashboards applying Bayesian updating and predictive analytics (see also [Poll Simulation](https://github.com/HamidAbbasi-R/Poll-Simulation) and [Loan Risk Analysis](https://github.com/HamidAbbasi-R/Loan-Risk-Analysis)).
